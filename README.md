# xtopdf

Conversão editorial de materiais HTML em PDF para estudo.

## Conteúdo

- `sources/Texto colado(6).txt`: primeira versão HTML de Bases da Ecologia.
- `sources/Texto colado (2).txt`: segunda versão HTML do mesmo conteúdo.
- `output/Biologia_ENEM_Bases_da_Ecologia_conteudo.pdf`: versão consolidada, deduplicada e revisada.

## Critérios aplicados

- fundo branco;
- conteúdo das duas fontes fundido sem repetição;
- gráficos e elementos vetoriais;
- texto selecionável;
- créditos, assinaturas, marcas, versões e rodapés removidos;
- campos de autoria, produtor e gerador removidos dos metadados do PDF.
